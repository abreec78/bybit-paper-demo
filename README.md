# Bybit paper demo

Виртуальный счёт BTC/USDT. Три независимых сценария по 30 USDT, плечо 1x, 3x, 5x. Сигнал пробоя сравнивает закрытие свечи с предыдущими 20 закрытиями. Модель открывает позицию на следующей свече и закрывает через 15 минут. Стратегия ранее показала убыток. Результаты служат для проверки работы системы.

Публичные данные Bybit V5. Биржевых ордеров и ключей нет. Исполнение моделируется по открытию свечи с издержками 0,085% на сторону. При достижении недельного порога в 1,50 USDT бот перестаёт открывать новые позиции до понедельника UTC. Убыток отдельной сделки может превысить порог. Финансирование, ликвидации и реальные ограничения биржевых ордеров не моделируются.

GitHub Actions запускает расчёт каждые 15 минут и сохраняет сделки и балансы в journal.json. При задержке расчёт догоняет свечи по истории. Это ретроспективное заполнение виртуального журнала.

Локальный запуск с Node.js 24: node paper.mjs
